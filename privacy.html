Privacy Policy

Last updated: November 23, 2026

AutoPoster Studio ("the Application") is an internal desktop automation tool used by the developer to upload creative media to authorized YouTube channels. We respect your privacy and handle user data strictly in accordance with Google API Services User Data Policy.

1. Data We Access and Store

The Application accesses the YouTube Data API v3 using user-granted OAuth 2.0 authorization tokens. Specifically:

  • Authentication Tokens: OAuth2 access and refresh tokens are stored locally on the user's personal computer. No tokens or credentials are ever sent to external third-party servers.
  • Channel Data: The application queries basic channel identity (title, ID) solely to confirm target upload destinations.
  • Content Upload: Video files, descriptions, titles, and thumbnails stored locally on the user's system are pushed directly to YouTube API endpoints.

2. Google API Compliance

AutoPoster Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Data Sharing and Third Parties

We do not sell, rent, disclose, or transfer any user data, tokens, or video materials to any external parties or advertising networks. All network operations occur exclusively between the user's local machine and Google's official endpoints (googleapis.com).
