Privacy Policy

Last updated November 24, 2026

Sundanese96 maintains Sundanese96 AutoPoster Studio, a private desktop application that uses YouTube API Services to upload and schedule videos and retrieve analytics for YouTube channels the operator authorizes. This policy describes the desktop application and this public information site.

Data the app accesses and how it uses it

  • Google authorization. Google handles sign-in and consent. The app receives OAuth access and refresh tokens to make the YouTube requests described below and renew authorization for future runs. Google handles the account password on its sign-in page.
  • Channel and video data. The app reads the connected channel’s identifier, name, uploads playlist and channel statistics. It reads recent video IDs, titles, publication dates and counts such as views, likes and comments. This data confirms the selected channel, identifies uploads and displays channel and video status.
  • Files and publishing settings. The app reads the selected video, thumbnail and metadata from folders configured by the operator. It sends the video, optional thumbnail, title, description, tags, category, language, audience and visibility settings, and any scheduled release time to YouTube. YouTube returns the video ID used to show the upload result and prevent duplicate uploads.
  • YouTube Analytics and Reporting. Analytics commands request channel and video performance data, including views, watch time, average view duration and percentage viewed, subscriber changes and aggregate viewer country. The reporting command can list or create a YouTube reporting job and download report data for the operator to inspect.
  • Connection checks. Some upload runs check the connection’s public IP and approximate country using IPinfo, ifconfig.me or api.myip.com. These services receive the ordinary network request and its source IP address. The requests carry no YouTube data, OAuth token or media. The app can also start or stop the operator’s installed Windscribe VPN when enabled.

Storage and retention

The app saves credentials in per-channel JSON files in the operator’s configured project storage. It also stores channel configuration, upload history, quota records and an upload status file in the relevant content folder. These records can include channel labels and titles, video IDs and URLs, upload timestamps and local folder paths. The app resets its quota tracker when it next runs on a new UTC date. The app keeps upload history and status records until the operator removes them. If the operator places those folders in a sync service, that service can retain copies.

Analytics and report results are fetched on demand and displayed or printed by the desktop app. The operator can save command output separately. This public GitHub Pages site contains public information about the app and has no app account, upload form or connection to the desktop token files.

Sharing and use limits

The desktop app sends OAuth requests to Google and exchanges media, publishing settings, channel information and report requests with the relevant YouTube APIs. YouTube handles uploaded videos according to the selected visibility setting, including release to the public when the operator selects public visibility. Google’s handling of data is described in the Google Privacy Policy.

Use of Google user data is limited to providing the authorization, publishing, duplicate prevention and reporting functions described here. Sundanese96 does not sell Google user data or use it for advertising, profiling or training AI models.

Revoking access and deleting data

To disconnect the desktop app, open Google Account permissions using the account that granted access and remove the app’s connection. Stop any scheduled desktop runs for the channel and remove its credential file and related local configuration and upload records, including any copies you keep in synced folders. You can also request help deleting stored app data by emailing the address below.

Manage or delete videos already uploaded to YouTube in YouTube Studio. Removing local app records or revoking access leaves those uploads in your YouTube channel until you take action there.
