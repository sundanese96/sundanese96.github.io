About the Application

AutoPoster Studio is a private creator tool designed to streamline video and short-form content publishing to YouTube channels via official YouTube Data API v3 endpoints.

Key Features

  • Automated video metadata tagging (titles, descriptions, educational categories).
  • Custom thumbnail synchronization.
  • Direct scheduling using official Google OAuth2 authentication.
